Overview

This project was completed as part of my Cybersecurity Internship at Veda Technology.
The purpose of this task is to understand basic networking concepts that are important in cybersecurity. 
It covers IP addresses, MAC addresses, ports, protocols, and network devices.

Objectives

- Understand IP addresses and MAC addresses.
- Learn about network ports and protocols.
- Understand the functions of routers, switches, and firewalls.
- Learn the importance of networking in cybersecurity.

Topics Covered

1. IP Address

An IP address is a logical address used to identify a device on a network and help route data to its destination.

Example: "192.168.1.10"

2. MAC Address

A MAC address is a link-layer identifier used for communication between devices on a local network.

Example: "00:1A:2B:3C:4D:5E"

3. Network Ports

Ports are logical numbers used by network services and applications to receive data.

Examples:

- HTTP: TCP port 80
- HTTPS: TCP port 443
- SSH: TCP port 22
- DNS: Port 53

4. Network Protocols

Protocols are rules that allow devices to communicate over a network.

Examples:

- TCP
- UDP
- IP
- HTTP and HTTPS
- DNS
- DHCP

5. Network Devices

- Router: Connects different networks and forwards data packets.
- Switch: Connects devices within a local area network.
- Firewall: Filters network traffic according to security rules.
- Access Point: Provides wireless network connectivity.

Importance in Cybersecurity

Networking knowledge helps cybersecurity professionals understand network traffic, investigate suspicious connections, identify exposed services, configure firewalls, and protect systems from network-based threats.

Security Best Practices

- Use strong passwords and multi-factor authentication.
- Keep network devices updated.
- Disable unused services and ports.
- Secure Wi-Fi networks.
- Configure firewall rules properly.
- Monitor network traffic and logs.
